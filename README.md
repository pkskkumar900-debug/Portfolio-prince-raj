🚀 About

ImPrince Tectra is the personal portfolio of Prince Raj, built around a futuristic digital identity and an AI-first development approach.

The website combines modern frontend engineering, interactive animations, responsive UI, data visualization, and Google Gemini integration into a single immersive experience.

It is designed not only as a portfolio, but also as a living showcase of experimentation, engineering, and AI-driven product development.

⚡ Getting Started

Requirements

Before running the project, make sure you have:

- Node.js 18+
- npm
- Google Gemini API key

Clone

git clone https://github.com/pkskkumar900-debug/Portfolio-prince-raj.git
cd Portfolio-prince-raj

Install

npm install

Environment

Create your local environment file:

cp .env.example .env

Configure:

GEMINI_API_KEY="YOUR_GEMINI_API_KEY"
APP_URL="http://localhost:3000"

«Never commit your real API keys to GitHub.»

Development

npm run dev
